# 1. 命令模式

> 命令是「具现化的方法调用」——把一次方法调用封装成一个可执行对象。

本章用四个可运行的 C# 控制台项目，逐级还原《游戏编程模式》第一章的演进过程。
每一步只比上一步多一层概念，建议从 0 开始按顺序读。

## 四个阶段

| 目录 | 书里对应 | 这一步多出了什么 |
| --- | --- | --- |
| `0.改进前-硬编码输入` | 章节开头的 `if (isPressed(X)) jump();` | 能跑，但按键与动作在代码里焊死，玩家不能改键 |
| `1.命令对象-按键重映射` | 「命令是具现化的方法调用」 | 抽出 `ICommand`，按键与命令之间隔一张绑定表，可在运行时换键；用空对象替代 null 判断 |
| `2.给角色的指令-延迟执行` | 「给角色的指令」小节 | `Execute(actor)` 把作用对象变成参数；`HandleInput()` 改为**返回**命令而不是执行，因此可以延迟执行、作用于任意角色，AI 也能生产命令 |
| `3.撤销和重做` | 「撤销和重做」小节 | 增加 `Undo()`，配合命令列表 + 当前指针，支持多步撤销与重做 |

## 运行方式

### 方式一：本机有 .NET SDK

需要 .NET **8 或更高**版本（`dotnet --version` 自查）。

```bash
cd 0.改进前-硬编码输入
dotnet run
```

Windows 也可以直接双击目录下的 `运行.cmd`；macOS / Linux 执行 `./运行.sh`。
脚本会先检查有没有 `dotnet`，没有就给出中文提示。

### 方式二：本机什么都没装

到仓库的 **Releases** 页面下载对应平台（Windows / Linux / macOS）的压缩包，解压后直接运行，无需安装任何运行时。

## 操作说明

| 目录 | 按键 |
| --- | --- |
| 0.改进前-硬编码输入 | `X` 跳跃、`Y` 开火、`A` 换武器、`B` 无效动作、`Esc` 退出 |
| 1.命令对象-按键重映射 | 同上，另有 `F1` 把跳跃键从 `X` 改绑到 `Z` |
| 2.给角色的指令-延迟执行 | `X` 跳跃、`Y` 开火、`Tab` 切换当前角色、`Esc` 退出 |
| 3.撤销和重做 | 方向键移动、`Ctrl+Z` 撤销、`Ctrl+Y` 重做、`Esc` 退出 |

## 两点约定

- 所有项目固定 `TargetFramework = net8.0`，装 .NET 8 / 9 / 10 的读者都能构建
- 仓库**不含** `global.json`，不会锁定 SDK 版本
